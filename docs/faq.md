# FAQ

## Os links são todos oficiais?

Não. O guia reúne links oficiais, comerciais e de comunidade. Sempre confira informações sensíveis em fontes oficiais.

## Qual a diferença entre "Por tema" e "Por cidade"?

- **Por tema:** recursos válidos para Alemanha em geral.
- **Por cidade:** recursos locais e contatos regionais.

## Posso sugerir uma nova cidade?

Sim. Abra issue ou PR com conteúdo útil para a cidade (não apenas placeholder vazio).

## Por que os nomes de arquivos estão em inglês?

Para manter padrão técnico comum em repositórios GitHub e URLs estáveis, enquanto o conteúdo continua em pt-BR.

## Como sei se um link ainda funciona?

Priorize links revisados recentemente e, se encontrar problema, abra issue em "Reportar link quebrado".
